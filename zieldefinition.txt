Purpose & context Horst is the sole developer and operator of WetterExtended (GitHub: IVOBLA/WetterExtended, private), a sophisticated storm cell detection, tracking, and warning system for Kärnten (Carinthia), Austria. The system runs on a Raspberry Pi 5 + Hailo-8 accelerator at /home/ki-pi/wetterprojekt, with a Lenovo ThinkCentre M910q (Ubuntu x86) as a separate trainer machine for ML model training and Hailo DFC compilation. Stack: Python/Flask backend, React/Vite/Tailwind/Leaflet frontend, three systemd services (wetterprojekt, wetterprojekt-scheduler, wetterprojekt-admin), nginx reverse proxy, LightGBM/LSTM/ConvLSTM models, APScheduler. Data sources: ARSO INCA radar (KMZ), GeoSphere Austria (AROME, TAWES, Nowcast), Open-Meteo (icond2, iconglobal), EUMETView/MSG IR108 satellite, Blitzortung lightning, Copernicus DEM 30m. Notification channels: Email (SMTP, HTML, per-location recipients) and WhatsApp (CallMeBot). WhatsApp sends warnings only — never all-clear notifications (explicit architectural decision). Working language: German throughout (code comments, logs, documentation, Claude responses). Key people/docs: HAILOINTEGRATION.md is the canonical bug/feature tracking document (B-series numbered entries). Zieldefinition:

Das Projekt muss auf radarbildern Regen/Gewitterzellen erkennen und klassififzieren.

Die Schwellwerte (farben) dafür müssen in einem Admin Panel wartbar sein.

Die Zugrichtung der Zellen die über dem Schwellwert liegen muss vorrausberechnet werden. Dazu muss Maschinelles lernen verwendet werden (sofern vorhanden)

Wenn keine Modeldaten vorhanden sind, so muss der Pfad alternativ aus den letzen Bewegungen errechnet werden.

Beim Maschinellen Lernen müssen folgende Faktoren berücksichtigt werden:

Wetterdaten die über internet zur verfügung stehen (wind, Temperatur, wolkenhöhe usw...)

Position der Zelle (aufgrund der Geographie ziehen zellen an einen bestimmten Punkt oft auch eine bestimmte Richtung)

Jahreszeit (datum +  uhrzeit)

Über ein Admin Panel muss der benutzer sämtlich konfigurationen vornehmen können.

Der Lernfortschritt und die Qualität aller Modelle muss graphisch dargestellt werden.

Die vorhersage muss mit den realen Werten verglichen werden.(bei erreichen des jeweilegen vorhersagezeitraum)

Die durchnittliche abweichung muss im adminpanel graphisch (über einen einstellbaren Zeitraum) dargestellt werden

Es muss für den benutzer eine leaflet karte geben wo er die Zellen verfolgen und die aktuellen sowie vorhersagewerte (zB Pfeile) angezeigt bekommt.

Im Admin Panel muss es möglich sein, mehrere orte (und einen umkreis um die orte) defninieren zu können.

Durchquert, steift oder berührt eine Zelle im vorhsagezeitraum den Umkreis eines ortes so ist dieser in der farbe des Vorhersagepfeiles zu markieren.

Im Admin panel müssen 5 vorhersagezeiträume + plus deren Pfeilfarben definiert werden können (default 10,20,30,40,60 Minuten). 

Es muss auf der Seite mit der Karte eine Farblegende geben

Alle GUI Themen müssen mit node.js (react) umgesetzt werden.

install.sh muss allen notwendigen dinge installieren/konfigurieren bezw. prüfen ob nicht schon konfiguriert/installiert (wenn vollinstallation)

kann install.sh das nicht automatisch machen, so muss im terminal angezeigt werden, was der benutzer machen muss.

Das trainieren der modelle muss zu einem definierbaren Zeitpunkt durchgeführt werden können.

Zielhardware: Raspberry Pi 5 B, Hailo-8 AI, 16GB, 26 TOPS

Die errechneten daten (aus python teil) müssen als Json objekte an den GUI teil übergeben werden. (Api?)

Wichtig, alle unnötigen Requests an Fremdsysteme müssen vermieden werden.

Die Fremdsysteme haben unterschiedliche aktualisierungsintervalle, berücksichtige diese.

Gewitter bleiben oft an Bergen hängen oder folgen tälern -> die bevorzugte bewegungsrichtungen muss das modell aber aus Trainingsdaten aus ähnlichen Situationen lernen. 

Geländeinformationen müssen für ganz Kärnten vorhanden sein und auch die Großwetterlage muss berücksichtigt werden

im admin panel muss sichtbar sein, wieviele requests pro tag an jede externe schnittstelle gesndet wurde
